# Zapatas — App

Esta es la aplicación publicada (calculadora de zapatas: rígido, Winkler,
Pasternak, punzonamiento y diseño de acero).

**Este repositorio se genera y actualiza automáticamente.** El código
fuente vive en un repositorio privado aparte; aquí solo llegan los
archivos ya compilados (`zapatas.wasm`, `zapatas.js`) y la página
(`index.html`). No edites archivos aquí directamente — cualquier cambio
se perderá en la siguiente publicación automática.

Sitio en vivo: (se activa en Settings → Pages de este repositorio).
